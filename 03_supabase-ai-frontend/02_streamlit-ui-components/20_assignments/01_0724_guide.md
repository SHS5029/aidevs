# 로그인과 설문 화면 전환 실습

## 1. 학습 목표

이 예제에서는 Streamlit으로 다음 화면 흐름을 구현합니다.

```text
로그인 화면
    ↓ 로그인 성공
설문 작성 화면
    ↓ 설문 제출
설문 결과 화면
    ↓ 다시 작성
설문 작성 화면
```

화면 오른쪽 위의 `LOGOUT` 버튼을 누르면 다시 로그인 화면으로 돌아갑니다.

이 실습의 핵심은 다음과 같습니다.

- `st.form()`으로 여러 입력값을 한 번에 제출합니다.
- `st.session_state`에 설문 결과와 현재 화면을 저장합니다.
- `st.rerun()`으로 변경된 상태에 맞게 화면을 다시 그립니다.
- 브라우저 세션 저장소에 로그인 상태를 저장합니다.
- 로그인, 설문, 결과 화면의 책임을 함수로 분리합니다.

## 2. Streamlit 화면 전환 이해하기

Streamlit은 일반적인 웹 프레임워크처럼 페이지 일부만 순서대로 실행하지 않습니다. 버튼을 누르거나 입력값이 변경되면 Python 파일 전체가 위에서 아래로 다시 실행됩니다.

따라서 다음과 같은 일반 변수만 사용하면 화면 상태를 안정적으로 유지하기 어렵습니다.

```python
current_page = "result"
```

재실행 후에도 값을 유지하려면 `st.session_state`를 사용합니다.

```python
st.session_state.display_state = "result"
```

이 예제에서는 `display_state`에 다음 두 값 중 하나를 저장합니다.

| 값 | 표시할 화면 |
| --- | --- |
| `"survey"` | 설문 작성 화면 |
| `"result"` | 설문 결과 화면 |

## 3. 완성 코드

아래 코드를 `01_0724.py`에 적용해 실행할 수 있습니다.

```python
# Streamlit으로 로그인 → 설문 → 결과 화면 전환을 연습하는 예제입니다.

import streamlit as st
from streamlit_session_browser_storage import SessionStorage


# SessionStorage는 브라우저의 sessionStorage를 Streamlit에서 사용하도록 도와줍니다.
# 브라우저 탭을 사용하는 동안 로그인 상태를 저장하는 용도로 사용합니다.
storage = SessionStorage()

# sessionStorage에서 로그인 상태를 읽습니다.
# 저장된 값이 없으면 None, 로그인 상태이면 "login",
# 로그아웃 상태이면 "logout"이 반환됩니다.
loginout = storage.getItem("loginout")


# --------------------------------------------------------------------
# 1. Streamlit 세션 상태 초기화
# --------------------------------------------------------------------

# display_state는 로그인 이후에 설문 화면과 결과 화면 중
# 어떤 화면을 보여 줄지 결정합니다.
if "display_state" not in st.session_state:
    st.session_state.display_state = "survey"

# 로그인 ID 입력창에서 사용할 시작값입니다.
# key="input_login_id"인 위젯의 값과 연결됩니다.
if "input_login_id" not in st.session_state:
    st.session_state.input_login_id = ""

# 로그인 비밀번호 입력창에서 사용할 시작값입니다.
# key="input_login_pwd"인 위젯의 값과 연결됩니다.
if "input_login_pwd" not in st.session_state:
    st.session_state.input_login_pwd = ""


# --------------------------------------------------------------------
# 2. 공통 동작 함수
# --------------------------------------------------------------------

def reset_login_form():
    """로그인 입력창의 ID와 비밀번호를 빈 문자열로 초기화합니다."""

    st.session_state.input_login_id = ""
    st.session_state.input_login_pwd = ""


# --------------------------------------------------------------------
# 3. 설문 작성 화면
# --------------------------------------------------------------------

def load_survey_form():
    """설문 입력 폼을 표시하고 제출된 값을 세션 상태에 저장합니다."""

    st.title("간단 설문 폼")

    # st.form 내부의 위젯 값은 사용자가 제출 버튼을 누를 때
    # 한꺼번에 Python 코드로 전달됩니다.
    with st.form("survey_form"):
        # text_input의 반환값은 문자열입니다.
        name = st.text_input("이름")

        # selectbox의 반환값은 목록에서 현재 선택된 항목입니다.
        topic = st.selectbox(
            "가장 어려웠던 주제",
            ["실행", "입력", "레이아웃", "표", "차트"],
        )

        # slider의 반환값은 사용자가 선택한 정수입니다.
        satisfaction = st.slider(
            "수업 만족도",
            min_value=1,
            max_value=5,
            value=3,
        )

        # text_area는 여러 줄의 문자열을 입력받습니다.
        comment = st.text_area("추가 의견")

        # 모든 st.form에는 최소 한 개의 form_submit_button이 필요합니다.
        # 버튼을 누른 실행에서만 submitted가 True가 됩니다.
        submitted = st.form_submit_button("설문 제출")

    # 제출 이후의 처리는 form 블록 밖에서 수행합니다.
    # 이렇게 하면 입력 영역과 제출 이후 동작을 쉽게 구분할 수 있습니다.
    if submitted:
        # 일반 변수는 앱이 다시 실행되면 유지되지 않을 수 있으므로
        # 결과 화면에서 사용할 값을 session_state에 저장합니다.
        st.session_state.saved_data = {
            "name": name,
            "topic": topic,
            "satisfaction": satisfaction,
            "comment": comment,
        }

        # 다음 실행에서는 설문 폼 대신 결과 화면을 표시하도록 변경합니다.
        st.session_state.display_state = "result"

        # 변경된 display_state를 즉시 화면에 반영하기 위해 앱을 재실행합니다.
        st.rerun()


# --------------------------------------------------------------------
# 4. 설문 결과 화면
# --------------------------------------------------------------------

def load_survey_result():
    """세션 상태에 저장된 설문 결과를 화면에 표시합니다."""

    # 설문 제출 시 저장했던 딕셔너리를 가져옵니다.
    result = st.session_state.saved_data

    st.title("설문 결과")

    # 이름이 빈 문자열이면 화면에는 "미입력"을 표시합니다.
    st.write(f"이름: {result['name'] or '미입력'}")
    st.write(f"어려웠던 주제: {result['topic']}")
    st.write(f"만족도: {result['satisfaction']}")

    # comment가 빈 문자열이 아닐 때만 작성 내용을 표시합니다.
    if result["comment"]:
        st.caption(result["comment"])
    else:
        # 이 else는 "설문 제출 전"이 아니라
        # "설문은 제출했지만 추가 의견이 비어 있음"을 의미합니다.
        st.info("추가 의견이 없습니다.")

    # 결과 화면에서 다시 설문 화면으로 이동하는 버튼입니다.
    if st.button("설문 다시 작성"):
        st.session_state.display_state = "survey"
        st.rerun()


# --------------------------------------------------------------------
# 5. 로그인 화면
# --------------------------------------------------------------------

def load_login_form():
    """로그인 폼을 표시하고 올바른 계정인지 확인합니다."""

    st.title("LOGIN")

    with st.form("login_form"):
        # key를 지정하면 입력값이 같은 이름의 session_state 항목과 연결됩니다.
        input_id = st.text_input("ID 입력", key="input_login_id")
        input_pwd = st.text_input(
            "PWD 입력",
            type="password",
            key="input_login_pwd",
        )

        # 두 버튼을 한 줄에 배치합니다.
        submit_area, reset_area = st.columns(2)

        with submit_area:
            login_submit = st.form_submit_button("LOGIN")

        with reset_area:
            # RESET 버튼을 누르면 reset_login_form 함수가 먼저 실행됩니다.
            st.form_submit_button("RESET", on_click=reset_login_form)

    # 로그인 버튼을 눌렀을 때만 ID와 비밀번호를 검사합니다.
    if login_submit:
        if input_id == "id01" and input_pwd == "pwd01":
            # 브라우저 sessionStorage에 로그인 상태를 저장합니다.
            storage.setItem("loginout", "login")
            st.success("로그인에 성공했습니다.")
        else:
            st.error("ID 또는 비밀번호가 올바르지 않습니다.")


# --------------------------------------------------------------------
# 6. 로그인 이후 화면과 로그아웃 처리
# --------------------------------------------------------------------

def load_logged_in_page():
    """로그아웃 버튼과 현재 상태에 해당하는 화면을 표시합니다."""

    st.info("로그인했습니다.")

    # 설문 화면보다 먼저 로그아웃 버튼을 만들고 처리합니다.
    logout = st.button("LOGOUT")

    if logout:
        # 브라우저 sessionStorage의 로그인 상태를 로그아웃으로 변경합니다.
        storage.setItem("loginout", "logout")

        # 다음 로그인에서는 설문 작성 화면부터 시작하도록 초기화합니다.
        st.session_state.display_state = "survey"

        # SessionStorage는 브라우저 측에서 값을 기록하는 컴포넌트입니다.
        # 기록 직후 st.rerun()을 호출하면 저장 전에 재실행될 수 있으므로
        # 현재 실행만 여기서 중단합니다.
        st.stop()

    # 현재 display_state에 맞는 함수 하나만 실행합니다.
    if st.session_state.display_state == "survey":
        load_survey_form()
    elif st.session_state.display_state == "result":
        load_survey_result()


# --------------------------------------------------------------------
# 7. 앱의 최종 화면 분기
# --------------------------------------------------------------------

# 저장값이 정확히 "login"일 때만 로그인 이후 화면을 표시합니다.
# 값이 None이거나 "logout"이면 로그인 화면을 표시합니다.
if loginout == "login":
    load_logged_in_page()
else:
    load_login_form()
```

## 5. 주요 데이터 흐름

### 로그인

```text
LOGIN 버튼 클릭
→ ID와 비밀번호 검사
→ SessionStorage에 "login" 저장
→ 로그인 이후 화면 표시
```

### 설문 제출

```text
설문 제출 버튼 클릭
→ 입력값을 st.session_state.saved_data에 저장
→ display_state를 "result"로 변경
→ st.rerun()
→ 결과 화면 표시
```

### 로그아웃

```text
LOGOUT 버튼 클릭
→ SessionStorage에 "logout" 저장
→ display_state를 "survey"로 초기화
→ 현재 실행 중단
→ 로그인 화면 표시
```

## 6. 기존 코드에서 주의할 점

### 동일한 폼 키를 중복 사용하지 않기

한 번의 실행에서 다음 폼을 두 번 만들면 안 됩니다.

```python
with st.form("survey_form"):
    ...

with st.form("survey_form"):
    ...
```

Streamlit 위젯에는 고유한 식별자가 필요합니다. 동일한 키의 폼을 중복 생성하면 실행 오류가 발생하며, 폼 이후에 작성된 로그아웃 처리 코드도 실행되지 않습니다.

### 결과 출력 영역을 불필요한 폼으로 만들지 않기

`st.form()`은 여러 입력값을 모아서 제출할 때 사용합니다. 단순히 결과를 보여 주는 영역은 폼으로 감쌀 필요가 없습니다.

```python
# 권장
st.title("설문 결과")
st.write("결과 내용")
```

결과 영역을 폼으로 만들면 그 안에도 반드시 `st.form_submit_button()`을 넣어야 하므로 `Missing Submit Button` 경고가 발생할 수 있습니다.

### `st.rerun()`을 조건 없이 호출하지 않기

다음 코드는 앱을 반복해서 재실행할 수 있습니다.

```python
st.rerun()
```

`st.rerun()`은 제출 또는 화면 이동처럼 재실행이 필요한 조건 안에서만 호출합니다.

```python
if submitted:
    st.session_state.display_state = "result"
    st.rerun()
```

### 로그아웃을 화면 함수보다 먼저 처리하기

로그아웃 처리가 설문 함수 호출보다 아래에 있으면 설문 함수에서 오류가 발생했을 때 로그아웃 코드까지 도달하지 못합니다.

```python
# 권장 순서
if logout:
    # 로그아웃 처리
    ...

# 로그아웃이 아닌 경우에만 현재 화면을 출력
load_survey_form()
```
